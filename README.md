# marleeseverson.com

Game programming portfolio of Marlee Severson. Live at [marleeseverson.com](https://marleeseverson.com).

Built with Vite, React, TypeScript and GSAP (ScrollTrigger). Fonts are self-hosted (Bricolage Grotesque, JetBrains Mono). No runtime dependencies beyond React and GSAP.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-checks, then builds to dist/
npm run preview    # serves dist/
```

## Deploy

Pushes to `main` build and deploy through `.github/workflows/deploy.yml`.
One-time setup: in the repository settings, **Pages → Build and deployment → Source** must be set to **GitHub Actions**.
`public/CNAME` keeps the custom domain attached to each deploy.

## Where things live

| Path | What |
| --- | --- |
| `src/data/profile.ts` | Name, bio, education, experience, links, resume setting |
| `src/data/projects.ts` | All project copy, awards, media lists and links |
| `src/data/skills.ts` | Skills matrix rows/columns and concepts |
| `src/components/` | One component (+ CSS module) per section |
| `src/sim/agents.ts` | The Idle → Patrol → Chase → Attack simulation drawn on the hero |
| `src/resume/` | The print-ready resume page (`/resume.html`), generated from the same data |
| `assets-src/<project>/` | Original screenshots / GIFs / videos (source of truth for media) |
| `public/media/` | Generated, optimized media. Don't edit by hand. |
| `scripts/optimize-media.mjs` | Builds `public/media` and `src/data/media-manifest.json` |

## Adding screenshots, GIFs and videos

1. Drop the file into `assets-src/<project-slug>/` with a descriptive name, e.g. `assets-src/crystal-cavern/song-two-combo.png`.
2. Run `npm run media`. PNG/JPG become responsive WebP variants; GIF/MP4/WebM are copied through.
3. Reference it in `src/data/projects.ts`:

```ts
// image (key = "<slug>/<filename without extension>")
{ kind: 'image', id: 'crystal-cavern/song-two-combo', alt: '…', caption: '…' }
// gif
{ kind: 'gif', src: '/media/crystal-cavern/combo.gif', alt: '…', caption: '…' }
// video (poster optional; use a manifest image path for it)
{ kind: 'video', src: '/media/crystal-cavern/boss.mp4', poster: '/media/crystal-cavern/song-two-combo-1000.webp', alt: '…', caption: '…' }
```

Featured projects have a `hero` item plus a `gallery` array that renders as a grid under the write-up. Secondary projects use `media`.
If a screenshot needs cropping (capture chrome, itch.io frame), add an entry to `CROPS` in `scripts/optimize-media.mjs`.

## Resume

`/resume.html` is a print-ready page built from the site data; "Print / Save as PDF" uses the browser's print dialog.
To link a PDF instead, put it in `public/` and set `resumePdf` in `src/data/profile.ts` (e.g. `'/Marlee-Severson-Resume.pdf'`). Every Resume link on the site follows that setting.
